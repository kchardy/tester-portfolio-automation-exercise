# Manual Test Cases
This directory contains manual test cases and their execution results for the Automation Exercise web application.

## Files
- `automation-exercise-test-cases.xlsx` – formatted Excel workbook containing the test cases and execution results
- `automation-exercise-test-cases.csv` – CSV version of the same test cases

## Test execution summary
- Total test cases: 22
- Passed: 16
- Failed: 6

Failed test cases are linked to defect reports using identifiers from `BUG-001` to `BUG-006`. The complete test summary is available in the [`test-report`](../test-report/automation-exercise-test-summary-report.md) directory.
