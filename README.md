# QA Portfolio – Automation Exercise
[![Playwright Tests](https://github.com/kchardy/tester-portfolio-automation-exercise/actions/workflows/playwright.yml/badge.svg)](https://github.com/kchardy/tester-portfolio-automation-exercise/actions/workflows/playwright.yml)

This repository documents manual, API and automated UI testing of the [Automation Exercise](https://automationexercise.com/) e-commerce application.

## Project scope
The project includes:

- Test planning
- Manual test cases with execution results
- Defect reports created in GitHub Issues
- Manual test summary report
- API tests created in Postman
- Automated UI tests created with Playwright
- Automated test execution using GitHub Actions
